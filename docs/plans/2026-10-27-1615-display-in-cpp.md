# The e-paper display in C++

Date: 2026-10-27 16:15 EDT

## Context

The screen program was the project's only Python: it duplicated the wheel,
config and database code the C++ programs have, and cost a resident Python on
a 416 MB Pi. It becomes C++26 like the others and shares their code: FreeType
and HarfBuzz for text, libgpiod for the pins, spidev and i2c-dev for the panel
and touch, libpng for previews. The screens are proven against the Python
version pixel by pixel before Python goes, with three deliberate differences
(hinted text spacing, a margin for the calendar's W, an even 2 px line). The
rules are in [display/](../intents/display/).
