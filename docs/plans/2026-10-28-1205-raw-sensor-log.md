# A raw sensor log for debugging

Date: 2026-10-28 12:05 EDT

## Context

When the sensor misbehaves (a restart read as 65,531 turns, turns missed
waking up), the database holds only what the logger made of it, and the
journal only the measurements that added turns. A raw log keeps every
measurement as the sensor sent it, what the logger made of it, and every
connection event, for a day or two, off unless turned on. Settled in
[ble/raw-log.md](../intents/ble/raw-log.md).

## Tasks

- [x] Intent: what is logged, where, for how long, the settings, the size
- [x] `[sensor] raw_log` (off) and `raw_log_days` (2, 1-14), read live by the logger, on the settings page
- [x] The log: a file a day in `/var/lib/purrdometer/sensor-log/`, every measurement and event, days past the limit removed
- [x] The settings page links the log's days for download
- [x] Self-tests: the lines written, off writes nothing, old days removed, the settings saved
- [x] On whiskerwheel: turned on from the settings page, and a spin shows up in the 2026-10-28 downloadable log with the exact measurement bytes and accounting result
